# WebDraw — BLOOD CANVAS 🩸

Клиентский веб-инструмент для рисования (слои, фигуры, кисть, штамп, заливка, undo/redo, сохранение в JPEG/.sdp).

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

## Структура

- `index.html` — разметка интерфейса
- `src/style.css` — чёрно-красная тема
- `src/main.js` — вся логика: холст, слои, инструменты, история, сохранение/загрузка
